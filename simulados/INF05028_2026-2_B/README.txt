IMPORTANTE:

1. COPIAR (não mover) a pasta chamada RENOMEAR_CARTAO para FORA DO PENDRIVE (para Área de Trabalho por exemplo) e renomeá-la com o seu número de cartão da UFRGS sem os zeros, e.g., se o código é 00123456 então a pasta deve se chamar 123456.
2. NÃO ALTERAR A ESTRUTURA INTERNA da pasta renomeada, não adicione, remova, ou renomeie arquivos dentro da pasta renomeada. A única exceção é que é permitido criar um binário chamado a.out por meio de `g++ code.cpp' junto aos códigos.
3. EDITE SOMENTE AS FUNÇÕES. Cada pasta dentro da pasta renomeada contém um exercício, contendo entrada, saída, e um código já com a parte de IO pronta. A descrição da questão está como comentário dentro do código. Somente o código dentro da função "solve" deve ser modificado.
4. Para verificar a corretude execute "g++ code.cpp && ./a.out < entradas.txt" (compila o código e executa o binário sobre as entradas). A saída no terminal pode ser comparada com o conteúdo do arquivo saídas.txt.
5. Corretude não é o suficiente para obter a pontuação máxima. É necessário que o algoritmo realmente seja do paradigma pedido e tenha a complexidade correta (o código será examinado pelo professor).
6. AO TERMINAR A PROVA, COPIE A PASTA RENOMEADA PARA DENTRO DA MESMA PASTA QUE CONTINHA A PASTA RENOMEAR_CARTAO. Use remover com segurança após a cópia terminar. Tire e coloque o pendrive de novo para verificar se a cópia ocorreu corretamente, se sim, remova com segurança novamente.
